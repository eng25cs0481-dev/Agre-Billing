# Agre Billing — Mobile App Guide

## Fast Shop Operations (Mobile POS)

The mobile application is built with **Expo + React Native**, optimized for floor sales, fast cart additions, customer lookup, and quick receipt recording.

### Core Mobile Workflows
1. **Quick POS Billing**: 1-tap product chip adding, quantity counters, customer search, instant Cash/UPI/Credit calculation.
2. **Real-time KPI Dashboard**: Today's sales count, total revenue, and pending dues summary.
3. **Stock & Price Lookup**: Check live warehouse/shop inventory on the spot.
4. **Customer Balances**: Instantly check outstanding amounts and record on-the-spot collections.
