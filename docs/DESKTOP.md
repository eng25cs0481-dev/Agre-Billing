# Agre Billing — Desktop Application Guide

## TallyPrime 7.1 Inspired Experience

The desktop application is built with **Tauri 2 + React + TypeScript + Vite**, utilizing custom Indigo design tokens for an information-dense, distraction-free environment.

### Gateway Navigation
- Press `Enter` or click on any section (Masters, Transactions, Reports, Utilities).
- Press `Esc` anywhere to navigate back to the Gateway.

### Global F-Key Shortcuts
- **F2**: Date selector
- **F5**: New Payment Voucher
- **F6**: New Receipt Voucher
- **F8**: New Sales Invoice / Voucher
- **F9**: New Purchase Voucher
- **Ctrl + S**: Save Voucher / Form
- **Ctrl + P**: Print Invoice / Report
- **Ctrl + N**: Create New Master Record
- **Ctrl + F**: Focus Search Bar

### High-Density Data Tables
- Keyboard navigation with `Up` / `Down` arrow keys and `Enter` to select/open.
- Real-time searching and filtering with sticky headers and footer totals.
